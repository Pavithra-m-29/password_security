# Password Security System using Arduino

## Project Overview
This project is a simple Password Security System built using Arduino, a 4x3 Keypad, and a 16x2 LCD Display.

## Proteus Simulation Output

![Proteus Simulation](Screenshot%202026-06-12%20203642.png)

## Components Used
- Arduino Uno
- 4x3 Matrix Keypad
- 16x2 LCD Display
- Proteus Design Suite

## Features
- Password Authentication
- LCD User Interface
- Password Masking (*)
- Clear Input Function
- Secure Access Verification
