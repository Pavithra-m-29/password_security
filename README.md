Password Security System using Arduino
*Project Overview

This project is a simple Password Security System built using Arduino, a 4x3 Keypad, and a 16x2 LCD Display. Users can enter a password through the keypad. If the entered password matches the stored password, the system displays "UNLOCKED"; otherwise, it displays "LOCKED".

*Components Used
1.Arduino Uno
2.4x3 Matrix Keypad
3.16x2 LCD Display
4.Jumper Wires
5.Proteus Simulation Software

*Features
1.Password authentication
2.LCD display for user interaction
3.Password masking using '*' characters
4.Clear input option using '*' key
5.Password verification using '#' key

*Working Principle
1.The LCD prompts the user to enter a password.
2.The user enters the password through the keypad.
3.Each entered digit is displayed as '*' for security.
4.Press '*' to clear the current input.
5.Press '#' to verify the password.
6.If the password is correct, the LCD displays UNLOCKED.
7.If the password is incorrect, the LCD displays LOCKED.
